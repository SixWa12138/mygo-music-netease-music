# 建议：为插件开放侧栏布局、页面标签和安全上传能力

## 问题

插件可以添加侧栏入口并返回 `Browse` 页面，但目前无法完整控制插件入口和歌单分组的位置、添加侧栏分隔线、在页面中显示原生标签，也无法调用应用的文件选择器上传用户选中的文件。此外，插件无法为应用内置的“我喜欢的音乐”页面提供封面。

网易云音乐插件需要这些能力来展示个人音乐库入口、播客分类标签、音乐云盘上传按钮，以及动态的喜欢歌曲封面。本地修改播放器可以实现这些功能，但播放器更新后补丁会被覆盖，因为插件 API 和宿主界面目前没有提供对应能力。

## 建议

希望为插件提供稳定、可检测的可选能力：

- 支持有序的侧栏分组和可选分隔线，并允许插件指定“创建的歌单”和“收藏的歌单”分组的位置；默认行为保持兼容现有插件。
- 支持插件 `Browse` 页面原生标签，包含标签标题、目标页面、选中状态，以及用于保持侧栏选中项的稳定导航页面。
- 允许插件为内置的喜欢歌曲页面提供可选封面；歌曲列表为空或封面加载失败时应有明确的默认显示。
- 提供受限的原生多文件选择器，可按声明的扩展名筛选，并报告逐文件进度、取消状态和错误。
- 提供宿主上传流，仅允许访问用户通过文件选择器明确选中的文件；支持进度与取消，并遵循插件声明的网络权限。

这些能力应保持可选，以便现有插件继续工作。插件可以通过特性检测判断宿主是否支持；不支持时仍可使用普通链接和浏览页面。

## 背景

网易云音乐插件及配套补丁：https://github.com/SixWa12138/mygo-music-netease-music

配套补丁实现了侧栏分组定位和分隔线、动态喜欢歌曲封面、`Browse.Tabs`、`Browse.NavigationPage`、`Browse.Upload`、`host.uploadFile` 和 `host.uploadCheckpoint`，并包含相应的原生界面及文件选择处理。补丁位于该仓库 `patches/` 目录：`mygo-sidebar.patch`、`mygo-liked-cover.patch` 和 `mygo-cloud-library.patch`。
